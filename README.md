# minecraft-mod-I9-23V
Учебный проект, дисциплина "Инструментальные средства разработки ПО", участник Мусин Ильнур.
Разработка мода для Minecraft с блоком "Энергокристалл"
## Участники
- Мусин Ильнур (И9-23В) — программирование, ресурсы, рецепт, поведение, документация
## Совместимость
- Minecraft: 1.21.1
- Fabric Loader: 0.16.10
- Fabric API: 0.107.0+1.21.1
- Java: 21
## Установка
1. Установите Fabric Loader и Fabric API 1.21.1
2. Скопируйте файл minecraft-mod-I9-23V-0.1.0.jar в папку mods
3. Запустите игру. Блок «Энергокристалл» доступен во вкладке «Строительные блоки» и по рецепту
## Использование
Объект: блок energy_crystal (Энергокристалл). Свойства: светимость 8, прочность/сопротивление, добыча киркой. Назначение: освещение и декор. При использовании блока появляется сообщение
## Ограничения
- Нет собственного звукового эффекта
- Плоская текстура без 3D-модели
## Структура проекта
- src/main/java — исходный код модификации
- src/main/resources — ресурсы и конфигурация модификации
## Игровой объект
Блок: energy_crystal (светящийся декоративный блок)
## Свойства объекта
- strength(3.0f, 6.0f) — прочность и сопротивление блока
- luminance(8) — уровень освещения (блок светится)
- requiresTool() — добыча подходящим инструментом
## Рецепт
Рецепт: 4 стекла + 4 редстоуна + 1 алмаз (сетка 3x3). Стоимость согласована со свойствами: светящийся блок стоит редстоуна и имеет защиту
## Поведение объекта
Сценарий:
1. Исходное состояние: блок energy_crystal размещён в мире
2. Действие игрока: игрок использует блок правой кнопкой мыши
3. Ожидаемый результат: игрок получает сообщение «Энергокристалл освещает пространство»
